## 17. Блоки внимания (Callouts)  
Работают в Obsidian, GitHub и некоторых других редакторах.  
*Синтаксис:* `> [!ТИП] Заголовок`  

| Тип                  | Синтаксис (в начале строки)      | Описание и Цвет (в Obsidian)          | Пример вида (упрощенно)              |
| :------------------- | :------------------------------- | :------------------------------------ | :----------------------------------- |
| **Заметка**          | `> [!NOTE]`                      | **Синий**. Общая информация.          | > **NOTE**<br>Текст заметки          |
| **Инфо**             | `> [!INFO]`                      | **Синий**. Дополнительные сведения.   | > **INFO**<br>Полезная информация    |
| **Совет**            | `> [!TIP]`                       | **Зеленый**. Лайфхаки и советы.       | > **TIP**<br>Попробуйте сделать так  |
| **Успех**            | `> [!SUCCESS]`                   | **Зеленый**. Выполнено успешно.       | > **SUCCESS**<br>Задача решена       |
| **Вопрос**           | `> [!QUESTION]`                  | **Оранжевый/Желтый**. Вопросы.        | > **QUESTION**<br>Как это работает?  |
| **Предупреждение**   | `> [!WARNING]`                   | **Оранжевый**. Важное предупреждение. | > **WARNING**<br>Будьте осторожны    |
| **Ошибка/Опасность** | `> [!FAILURE]` или `> [!DANGER]` | **Красный**. Критическая ошибка.      | > **FAILURE**<br>Операция не удалась |
| **Пример**           | `> [!EXAMPLE]`                   | **Фиолетовый**. Примеры решений.      | > **EXAMPLE**<br>Пример №1           |
| **Цитата**           | `> [!QUOTE]`                     | **Серый**. Цитата с автором.          | > **QUOTE**<br>Слова великих         |

## 18. Сворачиваемые блоки (Спойлеры)

Позволяют скрывать содержимое Callout-блока. Работает добавлением знака `+` или `-` после типа блока.  

| Что нужно                      | Синтаксис                | Пример                                        | Описание                                                    |
| :----------------------------- | :----------------------- | :-------------------------------------------- | :---------------------------------------------------------- |
| **Свернутый блок** (Спойлер)   | `> [!NOTE]- Заголовок`   | `> [!NOTE]- Скрытое решение`<br>`> Ответ: 42` | Блок будет **закрыт** по умолчанию. Раскрывается кликом.    |
| **Развернутый блок** (Спойлер) | `> [!NOTE]+ Заголовок`   | `> [!INFO]+ Важно`<br>`> Текст`               | Блок будет **открыт** по умолчанию, но его можно свернуть.  |
| **Без заголовка**              | `> [!NOTE]` (без текста) | `> [!TIP]`<br>`> Просто совет`                | Заголовок будет заменен на название типа (например, "Tip"). |

**Пример вложенности:**
```markdown
> [!FAQ]- Часто задаваемые вопросы
> > [!QUESTION] Как установить?
> > `sudo pacman -S package`
```
