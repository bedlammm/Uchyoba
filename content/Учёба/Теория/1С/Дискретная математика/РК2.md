# ТДНФ:
**Тупиковая ДНФ - дизъюнкция минимально набора простых импликант, необходимого для покрытия всех единиц функции, такая, что удаление любого слагаемого нарушает покрытие.**  
  
# МДНФ
**Минимальная ДНФ - ТДНФ, содержащая меньше всего литералов, по сравнению с другими ТДНФ.**  
*или*  
**МДНФ - ДНФ, которая получается в результате минимизации и содержит минимальное количество литералов среди всех тупиковых ДНФ.** 
  
# КрДНФ
**Кратчайшая ДНФ - тупиковая ДНФ, имеющая минимальное количество конъюнктивных членов (слагаемых).**
# СкДНФ
**Сокращённая ДНФ - дизъюнкция всех простых импликант функции.**
