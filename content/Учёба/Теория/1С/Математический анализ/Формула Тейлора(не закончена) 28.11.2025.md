# Многочлен Тейлора степени n, соответствующий f(x)
$$
P_n(x)=f(a)+f'(a)(x-a)+\frac{f''(a)}{2!}(x-a)^2+\dots+\frac{f^{(n)}(a)}{n!}(x-a)^n
$$  

# **Формула Тейлора:**

$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!} (x-a)^k + \bar{\bar{o}}((x-a)^n)$$

**$r_n(x)$ — остаточный член**   $0! = 1$  

1.  $r_n(x) = \bar{\bar{o}}((x-a)^n)$ — **формa Пеано**

2.  $r_n(x) = \frac{1}{(n+1)!} f^{(n+1)}(a + \theta(x-a)) \cdot (x-a)^{n+1}, \quad 0 < \theta < 1$ - **форма Лагранжа**  

# **Формула Маклорена**

$$ f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(0)}{k!} x^k + r_n(x) \quad U(0)$$
**- формула Тейлора с a=0**  
# Стандартные разложения
Вот исправленный вариант с заменой $o$ на $\bar{\bar{o}}$:

1.  $$e^x = 1 + x + \frac{x^2}{2!} + \dots + \frac{x^n}{n!} + \bar{\bar{o}}(x^n) = \sum_{k=0}^n \frac{f^{(k)}(0)}{k!} x^k + \bar{\bar{o}}(x^n)$$

2.  $$\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{4!} + \dots + (-1)^n \frac{x^{2n}}{(2n)!} + \bar{\bar{o}}(x^{2n+1})$$

3.  $$ \begin{gathered}\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} + \dots + (-1)^n \frac{x^{2n+1}}{(2n+1)!} + \bar{\bar{o}}(x^{2n+2})=\\
    = \sum_{k=0}^n (-1)^k \frac{x^{2k+1}}{(2k+1)!} + \bar{\bar{o}}(x^{2n+2}) \end{gathered} $$  

4.  $$(1+x)^\mu = 1 + \mu x + \frac{\mu(\mu-1)}{2} x^2 + \dots + \frac{\mu(\mu-1)\dots(\mu-n+1)}{n!} x^n + \bar{\bar{o}}(x^n)$$

5.  $$\frac{1}{1+x} = 1 - x + x^2 - x^3 + \dots + (-1)^n x^n + \bar{\bar{o}}(x^n)$$

6.  $$\frac{1}{1-x} = 1 + x + x^2 + x^3 + \dots + x^n + \bar{\bar{o}}(x^n)$$
7. $$ \ln(1+x)=x-\frac{x^2}2 +\frac{x^3}3\dots \frac{(-1)^{n-1}\cdot x^n}n+\bar{\bar{o}}(x^n) $$
