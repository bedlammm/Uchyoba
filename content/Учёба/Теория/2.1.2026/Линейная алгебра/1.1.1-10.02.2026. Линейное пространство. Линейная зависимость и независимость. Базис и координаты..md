# Линейное пространство 

> [!info]+ Линейное пространство
> Множество $V$ элементов $\bar x, \bar y,\bar z...$ любой природы называют линейным пространством, если выполнены следующие условия:
> 1. На множестве $V$ определена операция **сложения** элементов, то есть каждой паре элементов $\bar x$ и $\bar y$ поставлен в соответствие элемент $\bar z\in V$, обозначаемый $\bar z=\bar x+\bar y$, и называемый суммой элементов $\bar x$ и $\bar y$.  
> 2. Для элементов множества $V$ определена операция **умножения на действительное число**, то есть каждому элементу $\forall\space\bar x\in V$ поставлен в соответствие элемент $\bar z\in V$, обозначаемый $\lambda \bar x=\bar z$, и называемый произведением элемента $\bar x$ на действительное число $\lambda$.  
>
>*Указанные операции - **линейные операции** - подчиняются аксиомам линейного пространства:*
>
>> [!example] Аксиомы линейного пространства
>>1.  $\bar x + \bar y = \bar y + \bar x$ (коммутативность).
>>2.  $(\bar x + \bar y) + \bar z = \bar x + (\bar y + \bar z)$ (ассоциативность сложения).
>>3.  $\exists \bar\theta \in V: \forall \bar x \in V, \bar x + \bar\theta = \bar x$ (существование нуля).
>>4.  $\forall \bar x \in V, \exists \bar x': \bar x + \bar x' = \bar\theta$ (существование противоположного элемента).
>> ---
>>5.  $1 \cdot \bar x = \bar x$ (унитарность).
>>6.  $\alpha(\beta \bar x) = (\alpha \beta)\bar x$ (ассоциативность умножения).
>>7.  $(\alpha + \beta)\bar x = \alpha \bar x + \beta \bar x$ (дистрибутивность по скалярам).
>>8.  $\alpha(\bar x + \bar y) = \alpha \bar x + \alpha \bar y$ (дистрибутивность по векторам).

>[!example]+ Свойства линейного пространства
>1) **Свойство:** Если $\exists\space{\bar\theta}$, то он единственный
> > [!quote]- **Доказательство:** 
> >Пусть $\bar{\theta}_1$ и $\bar{\theta}_2$ - нейтральные элементы
> >$\begin{gathered}\Downarrow\\ \begin{rcases} \bar{\theta}_1 + \bar{\theta}_2 = \bar{\theta}_1 \\ \bar{\theta}_1 + \bar{\theta}_2 = \bar{\theta}_2 + \bar{\theta}_1 = \bar{\theta}_2 \end{rcases} \Rightarrow \bar{\theta}_1 = \bar{\theta}_2\end{gathered}$
>2) **Свойство:** Если $\bar{x} \in V \ \exists \text{ единственный противоположный элемент } \bar{x}'\in V$
> > [!quote]- **Доказательство:** 
> > Пусть элементы $\bar{x}'\in V \text{ и } \bar{x}''\in V$ - противоположные элементу $\bar x\in V$
> >$$
\begin{rcases}
\bar{x}'' + \bar{x} + \bar{x}' = \bar{x}'' + (\bar{x} + \bar{x}') = \bar{x}'' + \bar{\theta} = \bar{x}''\\
\bar{x}'' + \bar{x} + \bar{x}' = (\bar{x}'' + \bar{x}) + \bar{x}' = (\bar{x} + \bar{x}'') + \bar{x}' = \bar{\theta} + \bar{x}' = \bar{x}' + \bar{\theta} = \bar{x}'
\end{rcases}
\Rightarrow \bar{x}' = \bar{x}''
> $$
>3) **Свойство:** Если $\bar{x}' \text{ противоположный к } \bar{x}, \text{ то }\bar{x}' = (-1) \bar{x}$
>4) **Свойство:** $\forall \text{ вещественных } \alpha \text{ и } \bar{\theta} :\alpha \cdot \bar{\theta} = \bar{\theta}.$
>5) **Свойство:** Из равенства $\alpha \bar{x} = \bar{\theta} \Rightarrow \begin{cases} \text{либо } \alpha = 0 \\ \text{либо } \bar{x} = \bar{\theta} \end{cases}$

> [!info]+ Определение
> Разностью $\bar x-\bar y$ элементов $\bar x,\bar y \in V$ называют такой элемент $z\in V$, что выполняется равенство $\bar x=\bar y+\bar z$

# Линейная зависимость и независимость

> [!info]+ Определение
Систему элементов $x_1,...,x_n$ линейного пространства $V$ называют линейно зависимой, если найдутся такие числа $\alpha_1,...,\alpha_n$, не все равные 0, что $\alpha_1x_1+...+\alpha_nx_n=0$ $(1)$
Если равенство $(1)$ выполняется лишь при условии, что все $\alpha_1=\alpha_2=...=\alpha_n=0$, то система линейно независима.

>[!tip]+ Теорема
> **Чтобы система была линейно зависима, необходимо и достаточно, чтобы хотя бы один из этих элементов являлся линейно комбинацией остальных.**
>
> >[!quote]- Доказательство
> >Пусть дана система элементов $x_1, x_2, \dots, x_n$.
> > > [!todo] Необходимость ($\Rightarrow$) 
> > > **Дано:** система $x_1, x_2, \dots, x_n$ линейно зависима.
> > >**Доказать:** один из элементов выражается через остальные.
> > >1. По определению линейной зависимости существуют $\alpha_1, \alpha_2, \dots, \alpha_n$, не все равные нулю, такие что:
   $$\alpha_1 x_1 + \alpha_2 x_2 + \dots + \alpha_n x_n = \bar{\theta}$$
> > >2. Пусть $\alpha_k \neq 0$ (хотя бы один такой коэффициент существует).
> > >3. Перенесем слагаемое $\alpha_k x_k$ в правую часть:
   $$\alpha_k x_k = -\alpha_1 x_1 - \dots - \alpha_{k-1} x_{k-1} - \alpha_{k+1} x_{k+1} - \dots - \alpha_n x_n$$
> > >4. Разделим на $\alpha_k \neq 0$:
   $$ \begin{gathered}x_k = \left(-\frac{\alpha_1}{\alpha_k}\right) x_1 + \dots + \left(-\frac{\alpha_{k-1}}{\alpha_k}\right) x_{k-1} + \\ + \left(-\frac{\alpha_{k+1}}{\alpha_k}\right) x_{k+1} + \dots + \left(-\frac{\alpha_n}{\alpha_k}\right) x_n \end{gathered} $$
> > >5. Полученное выражение является линейной комбинацией остальных элементов.
> >
> > > [!todo] Достаточность ($\Leftarrow$)
**Дано:** один из элементов - $x_k$ - является линейной комбинацией остальных.
**Доказать:** система $x_1, x_2, \dots, x_n$ линейно зависима.
> > >1. По условию:
   $$x_k = \beta_1 x_1 + \dots + \beta_{k-1} x_{k-1} + \beta_{k+1} x_{k+1} + \dots + \beta_n x_n$$
> > >2. Перенесем $x_k$ в правую часть к остальным элементам:
   $$\beta_1 x_1 + \dots + \beta_{k-1} x_{k-1} + (-1) x_k + \beta_{k+1} x_{k+1} + \dots + \beta_n x_n = \bar{\theta}$$
> > >3. Мы получили линейную комбинацию, равную нулевому вектору, в которой коэффициент при $x_k=-1\neq0$.
> > >4. Следовательно, по определению, система элементов линейно зависима.

> [!example] Свойства линейной зависимости/независимости элементов
> 1. Если среди системы элементов $\bar x_1,..., \bar x_n$ $(2)$ найдётся хотя бы один нулевой элемент, то система $(2)$ линейно зависима.
> 2. Система элементов $(2)$, содержащая линейно зависимую подсистему элементов, линейно зависима. 
> 3. Если система $(2)$ линейно независима, то любая её подсистема тоже будет линейно независима. 

> [!warning] Понятия и свойства линейной зависимости и независимости элементов пространства переносится на матрицы-столбцы их координат.

# Базис и координаты

> [!info] Определение
> Упорядоченную систему элементов $\bar x_1,...,\bar x_n$ линейного пространства $V$ называют его базисом, если эти элементы линейно независимы и каждый элемент из пространства $V$ можно представить в виде их линейной комбинации - *разложить по элементам базиса*.
>
>**Для $\bar{x} = x_1 \bar{b}_1 + \dots + x_n \bar{b}_n$ справедливо:**
> 1. $\bar{b}_1, \dots, \bar{b}_n - \text{базис}$
> 2.  $x_1, \dots, x_n - \text{координаты } \bar{x} \text{ в } \{\bar{b}\}$
> ---
> **Обозначения:**
> 1. Базис: $\{\bar{b}\} = (\bar{b}_1, \dots, \bar{b}_n)$
> 2. Координаты: $X = \begin{pmatrix} x_1 \\ x_2 \\ \dots \\ x_n \end{pmatrix}$
> 3. $\bar{x} = \{\bar{b}\} X$
