Ниже представлен код, который строит именно такую функцию с вашими требованиями (жёлтый цвет, штрихпунктирная линия, подписи осей). Также я приложил описание того, как выглядит этот график.

### Код для построения (Python + Matplotlib)

Если у вас установлен Python, вы можете запустить этот код:

```python
import matplotlib.pyplot as plt
import numpy as np

# Определяем функцию
def f(x):
    return 4*x**2 - 2*x + 6

# Создаем массив значений x (от -2 до 3, чтобы видеть вершину параболы)
x = np.linspace(-2, 3, 400)
y = f(x)

# Создаем график
plt.figure(figsize=(8, 6))

# Строим линию: 
# color='yellow' - жёлтый цвет
# linestyle='-.' - штрихпунктирная линия
# linewidth=2 - толщина линии для лучшей видимости
plt.plot(x, y, color='yellow', linestyle='-.', linewidth=2, label='f(x) = 4x² - 2x + 6')

# Подписываем оси
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('График функции f(x) = 4x² - 2x + 6')

# Добавляем сетку и темный фон, чтобы жёлтый цвет был хорошо виден
plt.grid(True, color='gray', linestyle='--', linewidth=0.5)
plt.gca().set_facecolor('#333333') # Темно-серый фон

plt.legend()
plt.show()
```

### Описание графика (для самостоятельного построения):

Если вам нужно построить его в тетради, вот основные характеристики этой функции:

1.  **Тип функции:** Это квадратичная функция, её графиком является **парабола**, ветви которой направлены **вверх** (так как коэффициент при $x^2$ равен $4$, что больше $0$).
2.  **Вершина параболы:**
    *   Координата $x_0 = -b / 2a = 2 / (2 \cdot 4) = 2 / 8 = \mathbf{0.25}$
    *   Координата $y_0 = f(0.25) = 4(0.25)^2 - 2(0.25) + 6 = 0.25 - 0.5 + 6 = \mathbf{5.75}$
    *   Точка вершины: **$(0.25; 5.75)$**.
3.  **Точка пересечения с осью Y:**
    *   При $x = 0$, $f(0) = \mathbf{6}$. Точка **$(0; 6)$**.
4.  **Пересечение с осью X:**
    *   Дискриминант $D = (-2)^2 - 4 \cdot 4 \cdot 6 = 4 - 96 = -92$.
    *   Так как $D < 0$, график **не пересекает ось X** (лежит полностью выше неё).

**Как рисовать:**
1. Отметьте вершину в точке $(0.25; 5.75)$.
2. Проведите через неё симметричную кривую (параболу), проходящую через точку $(0; 6)$ и $(0.5; 6)$.
3. Используйте **жёлтый карандаш** и рисуйте линию в стиле **«тире-точка-тире-точка»**.
4. Подпишите горизонтальную ось как **$x$**, а вертикальную как **$f(x)$** или **$y$**.
