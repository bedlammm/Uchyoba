
> [!info]+ Часть 1/2: Вычислительное ядро Python (NumPy и SymPy)

> ```python
> import numpy as np              # Работа с массивами и численные методы
> import sympy as sp              # Символьная математика (аналитика)
> import matplotlib.pyplot as plt # Построение графиков

> [!note]+ Создание массивов и векторизация (NumPy)
> В Python стандартные списки (`[1, 2, 3]`) не поддерживают математические операции. Для расчетов используются массивы `np.array`.
> 
> **Генерация координатных векторов (Для графиков):**
> Вместо оператора двоеточия из MATLAB (`a:step:b`), в NumPy применяются две функции:
> ```python
> # 1. np.arange(начало, конец, шаг) - аналог 0:0.2:2*pi
> # Конец НЕ включается в массив!
> x_discrete = np.arange(0, 2 * np.pi, 0.2) 
> 
> # 2. np.linspace(начало, конец, кол-во_точек) - ГЛАВНЫЙ ИНСТРУМЕНТ
> # Конец включается. Идеально для гладких графиков.
> x = np.linspace(-5, 5, 400) 
> ```
> 
> **Векторизация (Отличие от MATLAB):**
> В `numpy` математические операторы по умолчанию являются **поэлементными**. Вам **НЕ НУЖНО** ставить точки перед операциями (`.*`, `.^`), как это делается в MATLAB.
> Умножение `*`, деление `/` и возведение в степень `**` (в Python степень это две звездочки, а не `^`) применяются сразу ко всему массиву:
> ```python
> # Вычисление функции из Задачи 1
> y = 4 * x**2 - 2 * x + 6 
> 
> # Использование тригонометрии из ядра numpy
> y_trig = np.sin(x + 1) * np.cos(x)
> ```

> [!example]+ Линейная алгебра и Матрицы (Задачи 2, 6)
> В `numpy` матрицы создаются как вложенные массивы (списки списков).
> 
> **Создание матриц:**
> ```python
> # Единичная матрица 3x3
> I = np.eye(3) 
> 
> # Ручной ввод матрицы 3x3
> A = np.array([
>     [2, 1, 3],
>     [4, 0, 1],
>     [5, 2, 3]
> ])
> ```
> 
> **Манипуляции с матрицами (Конкатенация):**
> Для добавления новой строки (как в Задаче 2) используется функция вертикального стека `np.vstack`.
> ```python
> new_row = np.array([23, 46, 15])
> A_new = np.vstack([I, new_row]) # Склеивает I сверху и new_row снизу
> ```
> 
> **Вычисление определителя (Специфика вычислений):**
> Модуль `np.linalg` содержит инструменты линейной алгебры. При вычислении определителя `numpy` использует алгоритмы LU-разложения с арифметикой плавающей запятой (float64), поэтому ответ может выглядеть как `13.000000000000002`. Обязательно применяйте функцию округления `round()`.
> ```python
> detA = round(np.linalg.det(A))
> ```

> [!abstract]+ Символьная математика (Аналог Symbolic Math из MATLAB)
> Библиотека `SymPy` (`sympy as sp`) позволяет вычислять интегралы, пределы и производные аналитически — выдавая точные математические формулы с константами (например, $\pi$), а не приближенные числа.
> 
> **Объявление переменных:**
> ```python
> # Простое объявление переменной (аналог syms x)
> x_sym = sp.Symbol('x')
> 
> # Множественное объявление с физическими ограничениями (из Задачи 4)
> # real=True и positive=True помогают интегратору отбрасывать мнимые корни
> m, l, g, t = sp.symbols('m l g t', positive=True, real=True)
> ```
> 
> **Запись формул (Синтаксис SymPy):**
> Внутри `sympy` используются **свои** математические функции, отличные от `numpy`. Для логарифма — `sp.log`, для косинуса — `sp.cos`, для корня — `sp.sqrt`.
> ```python
> # Формула для Задачи 5
> y_sym = sp.log(sp.cos(x_sym))
> ```

> [!warning]+ Символьное дифференцирование и интегрирование (Задачи 4, 5, 8)
> 
> **Дифференцирование (Поиск производной):**
> Функция `sp.diff(выражение, переменная)`. Метод `.simplify()` упрощает полученное выражение (например, схлопывает основное тригонометрическое тождество).
> ```python
> dy_dx = sp.diff(y_sym, x_sym)
> # Выражение под корнем для длины дуги: sqrt(1 + (y')^2)
> L_expr = sp.sqrt(1 + dy_dx**2).simplify()
> ```
> 
> **Определенный интеграл:**
> Функция `sp.integrate(выражение, (переменная, нижний_предел, верхний_предел))`.
> ```python
> # Вычисление длины дуги от 0 до pi/4 (Задача 5)
> L_sym = sp.integrate(L_expr, (x_sym, 0, sp.pi/4))
> 
> # Вычисление объема методом колец (Задача 8)
> V_expr = sp.pi * (x_sym**2 - (x_sym**2)**2)
> V_sym = sp.integrate(V_expr, (x_sym, 0, 1)) # Выведет 2*pi/15
> ```
> 
> **Перевод символьного ответа в число:**
> Чтобы получить вещественное число (например, `0.8814` из точного ответа `ln(1+sqrt(2))`), используется метод `.evalf()` с последующим приведением к базовому типу `float`.
> ```python
> L_val = float(L_sym.evalf())
> ```

> [!info]+ Часть 2/2: Визуализация данных и графики (Matplotlib)
> Эта часть документации охватывает работу с библиотекой `matplotlib`, которая является стандартом де-факто для построения графиков в Python. В отличие от MATLAB, где функции отрисовки глобальны, в Python рекомендуется использовать объектно-ориентированный подход: создание объекта фигуры (`fig`) и объекта осей (`ax`).

> [!example]+ Базовое построение 2D-графика и строгая стилизация (Задача 1, 5)
> Задания часто требуют специфичного оформления: определенный цвет фона, штрихпунктирные линии, легенды и маркеры на графиках.
> 
> **Инициализация окна и осей:**
> ```python
> import matplotlib.pyplot as plt
> 
> # Создаем фигуру размером 8х6 дюймов и объект осей (ax)
> fig, ax = plt.subplots(figsize=(8, 6))
> 
> # Установка цвета фона самих осей (полезно для контрастных желтых/белых линий)
> ax.set_facecolor('#4d4d4d') # Темно-серый цвет в HEX
> ```
> 
> **Отрисовка функции и маркеров:**
> Функция `plot()` принимает векторы X и Y, а параметры стиля передаются явными аргументами, в отличие от кратких строк MATLAB.
> ```python
> # linestyle='-.' (штрихпунктир), '--' (пунктир), ':' (точки)
> ax.plot(x, y, color='yellow', linestyle='-.', linewidth=2, label='f(x)')
> 
> # Добавление одиночных точек (например, границ интегрирования)
> ax.scatter([0, np.pi/4], [y_start, y_end], color='red', zorder=5) # zorder помещает точки поверх линии
> ```
> 
> **Оформление графика:**
> В объектно-ориентированном синтаксисе перед названиями функций пишется `set_`.
> ```python
> ax.set_title('График функции', fontsize=14)
> ax.set_xlabel('Ось X'); ax.set_ylabel('Ось Y')
> ax.grid(True, color='gray', linestyle='--') # Включение сетки
> ax.legend() # Отображение легенды (использует параметр label из ax.plot)
> plt.show()  # Команда для финального вывода графического окна
> ```

> [!note]+ Мультиграфики (Subplots) и полярные координаты (Задача 7)
> Если необходимо вывести несколько независимых графиков в одном окне, фигура разбивается на сетку с помощью `add_subplot(строк, столбцов, индекс)`.
> 
> ```python
> fig = plt.figure(figsize=(12, 10))
> fig.suptitle('Общий заголовок окна')
> 
> # 1. Обычный линейный график
> ax1 = fig.add_subplot(2, 2, 1)
> ax1.plot(x, y, 'b-')
> 
> # 2. Столбчатая диаграмма (Гистограмма)
> ax2 = fig.add_subplot(2, 2, 2)
> ax2.bar(x, y, color='teal')
> 
> # 3. Дискретный график (Стебли)
> ax3 = fig.add_subplot(2, 2, 3)
> # linefmt - стиль линии, markerfmt - стиль шляпки, basefmt - стиль нулевой оси
> ax3.stem(x, y, linefmt='r-', markerfmt='ro', basefmt='k-')
> 
> # 4. Полярная система координат
> # КРИТИЧЕСКИ ВАЖНО: необходимо явно указать параметр polar=True
> ax4 = fig.add_subplot(2, 2, 4, polar=True)
> ax4.plot(x, y, 'm-') # x интерпретируется как угол (радианы), y - как радиус-вектор
> 
> plt.tight_layout() # Автоматически выравнивает отступы между графиками, чтобы они не слипались
> ```

> [!abstract]+ Трехмерная графика и Параметризация (Задачи 3, 8)
> **Ключевое архитектурное отличие от MATLAB:** В библиотеке Matplotlib **нет** аналога функции `fimplicit3`. Нельзя просто передать уравнение $F(x,y,z)=0$ и получить график. Поверхности необходимо переводить в **параметрическую форму**.
> 
> **Подготовка 3D-осей:**
> ```python
> fig = plt.figure()
> ax = fig.add_subplot(111, projection='3d') # Указание 3D проекции обязательно!
> ```
> 
> **Параметризация гиперболоида (Задача 3):**
> Однополостный гиперболоид $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ строится через гиперболические косинус ($\cosh$) и синус ($\sinh$), зависящие от двух параметров $U$ и $V$.
> ```python
> u = np.linspace(-2, 2, 50)
> v = np.linspace(0, 2 * np.pi, 50)
> U, V = np.meshgrid(u, v) # Создание 2D-сетки из 1D-векторов
> 
> X = a * np.cosh(U) * np.cos(V)
> Y = b * np.cosh(U) * np.sin(V)
> Z = c * np.sinh(U)
> ```
> 
> **Параметризация тел вращения (Задача 8):**
> При вращении функции $y = f(x)$ вокруг оси OX (цилиндрическая система координат), координата X остается собой, а Y и Z вычисляются как проекции радиуса вращения.
> ```python
> x_val = np.linspace(0, 1, 50)
> theta = np.linspace(0, 2 * np.pi, 50) # Угол вращения на 360 градусов
> X_grid, Theta_grid = np.meshgrid(x_val, theta)
> 
> # Вычисление радиуса. Для параболы y = x^2 радиус R = x^2
> R_in = X_grid**2
> 
> # Проекция радиуса на оси Y и Z
> Y_in = R_in * np.cos(Theta_grid)
> Z_in = R_in * np.sin(Theta_grid)
> ```

> [!warning]+ Отрисовка поверхностей (plot_surface) и оформление сцены
> Полученные трехмерные матрицы X, Y, Z передаются в функцию `plot_surface`.
> 
> ```python
> # Отрисовка: cmap - цветовая шкала, alpha - прозрачность (от 0 до 1), edgecolor - отключение черной сетки
> surf = ax.plot_surface(X, Y, Z, cmap='jet', alpha=0.8, edgecolor='none')
> 
> # Добавление легенды цветов сбоку графика
> fig.colorbar(surf, ax=ax, shrink=0.5, aspect=10, label='Высота (Z)')
> 
> # Выравнивание масштабов осей (чтобы конус не казался сплюснутым)
> ax.set_box_aspect((1, 1, 1)) 
> ```
