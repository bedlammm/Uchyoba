
> [!note]+ Основы синтаксиса, переменные и рабочая среда
> MATLAB интерпретирует команды построчно. Главная особенность среды — отсутствие необходимости явного объявления типов данных (всё по умолчанию является массивом чисел с плавающей точкой `double`).
> 
> **Базовые команды управления средой (пишутся в начале каждого скрипта):**
> ```matlab
> clc;       % Очищает командное окно (терминал) от предыдущего вывода
> clear;     % Удаляет все переменные из оперативной памяти (Workspace)
> close all; % Закрывает все открытые окна с графиками
> ```
> 
> **Переменные и подавление вывода:**
> Точка с запятой (`;`) в конце строки — критически важный оператор. Он **подавляет вывод** результата операции в консоль, что ускоряет выполнение кода.
> ```matlab
> a = 5;     % Создаст переменную a, но ничего не выведет в консоль
> b = 10     % Создаст переменную b и выведет 'b = 10' в консоль
> ```
> 
> **Индексация (Отличие от Python/C++):**
> Индексация массивов в MATLAB **начинается с 1**, а не с 0.
> Обращение к элементам происходит через круглые скобки `()`.
> Для обращения к последнему элементу используется ключевое слово `end`.
> ```matlab
> vec = [10 20 30 40];
> first = vec(1);      % Вернет 10
> last = vec(end);     % Вернет 40
> sub = vec(2:end-1);  % Вернет [20 30] (срез массива)
> ```

> [!example]+ Создание векторов и матриц
> Векторы и матрицы создаются в квадратных скобках `[]`.
> Пробел или запятая (`,`) отделяют элементы в строке. Точка с запятой (`;`) означает переход на новую строку.
> 
> **Ручной ввод:**
> ```matlab
> row_vec = [1 2 3 4];       % Вектор-строка 1x4
> col_vec = [1; 2; 3; 4];    % Вектор-столбец 4x1
> A = [1 2 3; 4 5 6; 7 8 9]; % Матрица 3x3
> ```
> 
> **Автоматическая генерация массивов:**
> 1. **Оператор двоеточия** `начало:шаг:конец`. Генерирует вектор с заданным шагом. Если шаг не указан, он равен 1.
> ```matlab
> t = 0:0.1:2*pi;  % Вектор от 0 до 2π с шагом 0.1
> nums = 1:5;      % Эквивалентно [1 2 3 4 5]
> ```
> 2. **Функция `linspace(a, b, n)`**. Генерирует вектор из `n` равноотстоящих точек между `a` и `b`. Удобно, когда важен не шаг, а точное количество точек (например, для графиков).
> ```matlab
> x = linspace(-10, 10, 100); % 100 точек от -10 до 10
> ```
> 3. **Специальные матрицы:**
> ```matlab
> Z = zeros(3, 4); % Матрица нулей 3 строки, 4 столбца
> O = ones(2, 2);  % Матрица единиц 2x2
> E = eye(4);      % Единичная матрица 4x4 (нули, на главной диагонали единицы)
> ```

> [!warning]+ Векторизация и поэлементные операции (КРИТИЧЕСКИ ВАЖНО)
> MATLAB применяет математические функции (sin, cos, exp, log) сразу ко всему массиву. Вам **не нужны циклы** (`for` / `while`), чтобы посчитать функцию для набора точек.
> 
> Однако, стандартные операторы `*`, `/`, `^` выполняются по правилам **линейной алгебры** (матричное умножение).
> Если вам нужно умножить, поделить или возвести в степень каждый элемент массива независимо (например, при расчете координат графика $y = x^2$), необходимо использовать **операторы с точкой**: `.*`, `./`, `.^`.
> 
> ```matlab
> x = [1 2 3];
> y = [4 5 6];
> 
> % НЕПРАВИЛЬНО для вычисления y = x^2 (выдаст ошибку размерности):
> % res = x ^ 2; 
> 
> % ПРАВИЛЬНО (возведет каждый элемент в квадрат):
> res = x .^ 2;  % Результат: [1 4 9]
> 
> % Поэлементное умножение:
> mult = x .* y; % Результат: [4 10 18]
> 
> % Вычисление сложной функции для графика (комбинация):
> % f(x) = x^2 * sin(x) / (x + 1)
> f = (x .^ 2) .* sin(x) ./ (x + 1);
> ```

> [!abstract]+ Линейная алгебра и матричные операции
> MATLAB изначально создавался для линейной алгебры (Matrix Laboratory). Любые операции над матрицами встроены в ядро и предельно оптимизированы.
> 
> **Базовые характеристики матриц:**
> ```matlab
> A = [2 1 0; 1 2 1; 0 1 2];
> 
> det_A = det(A);      % Определитель матрицы
> inv_A = inv(A);      % Обратная матрица (A^(-1))
> trans_A = A';        % Транспонирование матрицы (замена строк на столбцы)
> rank_A = rank(A);    % Ранг матрицы
> tr_A = trace(A);     % След матрицы (сумма элементов главной диагонали)
> ```
> 
> **Собственные числа и векторы (для Задачи 6 в ряде вариантов):**
> ```matlab
> % Функция eig() возвращает собственные числа. 
> % При присвоении двум переменным [V, D]:
> % V - матрица, столбцы которой являются собственными векторами.
> % D - диагональная матрица с собственными числами.
> [V, D] = eig(A);
> ```
> 
> **Решение систем линейных уравнений (СЛАУ):**
> Система вида:
> $x + 2y - z = 4$
> $2x - y + 3z = 1$
> $3x + y - 2z = 5$
> 
> В матричном виде: $A \times X = B$.
> Вместо нахождения через обратную матрицу (`X = inv(A) * B`), в MATLAB используется **оператор левого деления `\`**, реализующий метод Гаусса (работает в разы быстрее и без накопления погрешности):
> ```matlab
> A = [1  2 -1; 
>      2 -1  3; 
>      3  1 -2];
> b = [4; 1; 5]; % Вектор-столбец свободных членов
> 
> X = A \ b;     % Вычисление корней [x; y; z]
> 
> % Метод Крамера для самописных реализаций (если потребуют строго по методу):
> det_main = det(A);
> x1 = det([b, A(:, 2:3)]) / det_main; % Замена 1-го столбца на вектор b
> ```

> [!example]+ Базовое построение функции (plot) и удержание графика
> Функция `plot(x, y)` строит график по массивам координат X и Y. Оба массива должны быть одинаковой длины.
> 
> **Базовый алгоритм построения:**
> ```matlab
> x = -10:0.1:10;       % 1. Задаем вектор X (область определения)
> y = 15 - 2 .* x;      % 2. Вычисляем Y (с использованием поэлементных операций .*)
> 
> figure;               % 3. Создаем новое графическое окно (чтобы не перезаписать старое)
> plot(x, y);           % 4. Отрисовываем график
> grid on;              % 5. Включаем отображение координатной сетки (обязательно для наглядности)
> ```
> 
> **Наложение графиков (hold on):**
> По умолчанию каждый новый вызов `plot` стирает предыдущий график. Чтобы нарисовать несколько функций в одних осях, используется `hold on`.
> ```matlab
> plot(x, y1);
> hold on;              % "Замораживаем" оси
> plot(x, y2);          % Второй график добавится поверх первого
> hold off;             % Снимаем заморозку
> ```

> [!note]+ Стилизация: цвет, тип линии и маркеры
> Задания часто требуют конкретный стиль (например: "в виде звездочек зеленым цветом" или "штрих-пунктирной линии"). В функцию `plot` третьим аргументом передается строка форматирования `plot(x, y, 'Цвет_Стиль_Маркер')`.
> 
> **Коды цветов:**
> `r` (red), `g` (green), `b` (blue), `y` (yellow), `k` (black), `w` (white), `c` (cyan/голубой), `m` (magenta/пурпурный).
> 
> **Типы линий:**
> `-` (непрерывная), `--` (пунктир), `:` (точечная), `-.` (штрих-пунктир).
> 
> **Маркеры узлов (точек):**
> `*` (звездочка), `o` (круг), `+` (плюс), `s` (квадрат), `d` (ромб), `^` (треугольник вверх), `h` (шестигранник - hexagram).
> 
> ```matlab
> % Примеры строго по заданиям вариантов:
> plot(x, y, 'g*');     % Зеленые звездочки (без линии, только точки)
> plot(x, y, 'g--*');   % Зеленый пунктир со звездочками в узлах
> plot(x, y, 'k:h');    % Черная точечная линия с шестигранниками
> plot(x, y, 'y-.');    % Желтая штрих-пунктирная линия
> 
> % Расширенные настройки стиля передаются парами 'Свойство', Значение
> plot(x, y, 'r-', 'LineWidth', 2);           % Красная линия толщиной 2
> plot(x, y, 'MarkerSize', 10, 'Color', 'b'); % Крупные маркеры, явное указание цвета
> ```

> [!warning]+ Обязательное оформление осей и легенды
> Методичка категорически требует **"подписывать оси"** на всех графиках. Без этих команд баллы за задачу снижаются.
> ```matlab
> xlabel('Ось X');          % Подпись оси абсцисс
> ylabel('Ось Y');          % Подпись оси ординат
> title('График функции');  % Заголовок графика
> 
> % Добавление легенды (если функций несколько)
> % Имена в легенде указываются в порядке вызова функций plot!
> legend('Функция 1', 'Функция 2', 'Location', 'best'); 
> ```

> [!abstract]+ Специфичные оси: Логарифмический масштаб и Полярные координаты
> В некоторых вариантах (например, Вар 4, Вар 9) требуются нестандартные системы координат.
> 
> **Логарифмический масштаб:**
> Вместо `plot` используются специальные функции. Логарифмический масштаб сжимает оси для функций, которые растут экспоненциально, чтобы показать поведение на больших интервалах.
> ```matlab
> semilogy(x, y);       % Логарифмическая шкала только по оси Y (Ось X обычная)
> semilogx(x, y);       % Логарифмическая шкала только по оси X (Ось Y обычная)
> loglog(x, y);         % Логарифмическая шкала по обеим осям
> ```
> 
> **Полярные координаты (Кардиоиды, спирали Архимеда):**
> Уравнения задаются не через $x$ и $y$, а через угол $\varphi$ (в радианах) и радиус-вектор $r$. Для отрисовки используется `polarplot`.
> ```matlab
> phi = 0:0.01:2*pi;          % Вектор углов от 0 до 2π
> r = 2 + 2 .* cos(phi);      % Вычисляем радиус (пример: кардиоида)
> 
> figure;
> polarplot(phi, r, 'r-');    % Построение в полярных осях
> title('Кардиоида');
> % xlabel и ylabel здесь не нужны, оси автоматически радиальные
> ```

> [!tip]+ Мультиграфики (subplot, stem, bar)
> Для вариантов (например, Вар 6, Вар 7), где сказано "Вывести несколько окон графики функции ... в стилях plot, bar, stem, polar и сравнить их".
> 
> Команда `subplot(строк, столбцов, номер_ячейки)` делит одно графическое окно на сетку и выбирает текущую ячейку для рисования.
> ```matlab
> x = 0:0.2:2*pi;
> y = sin(x + 1);
> 
> figure('Name', 'Сравнение стилей'); % Открываем окно
> 
> % 1. Обычный линейный график (в сетке 2x2, позиция 1 - верхний левый)
> subplot(2, 2, 1);
> plot(x, y);
> title('Стиль: plot'); xlabel('x'); ylabel('y');
> 
> % 2. Столбчатая диаграмма (гистограмма, позиция 2 - верхний правый)
> subplot(2, 2, 2);
> bar(x, y);
> title('Стиль: bar'); xlabel('x'); ylabel('y');
> 
> % 3. Дискретный график (леденцы на палочке, позиция 3 - нижний левый)
> subplot(2, 2, 3);
> stem(x, y);
> title('Стиль: stem'); xlabel('x'); ylabel('y');
> 
> % 4. Полярный график (позиция 4 - нижний правый)
> % ВАЖНО: для polarplot в subplot в новых версиях MATLAB нужно явно указать тип осей
> ax = subplot(2, 2, 4, char('polar')); 
> polarplot(x, y); % Здесь x выступает как угол, y - как радиус
> title('Стиль: polar');
> ```

> [!example]+ Базовый принцип: Генерация координатной сетки (meshgrid)
> В 2D-графике массив $x$ был одномерным вектором. В 3D-графике функция $z = f(x, y)$ зависит от двух переменных. Чтобы вычислить $z$ для каждой точки плоскости, одномерные векторы $x$ и $y$ необходимо преобразовать в двумерную матричную сетку координат. За это отвечает функция `meshgrid`.
> 
> **Алгоритм построения 3D-поверхности:**
> ```matlab
> % 1. Задаем одномерные границы по осям X и Y
> x_vec = -5:0.2:5;
> y_vec = -5:0.2:5;
> 
> % 2. Генерируем координатную сетку (матрицы X и Y)
> [X, Y] = meshgrid(x_vec, y_vec);
> 
> % 3. Вычисляем Z (обязательно используем точки .*, ./, .^ для поэлементных операций!)
> % Пример: параболоид z = x^2 + y^2
> Z = X.^2 + Y.^2; 
> ```

> [!note]+ Построение поверхностей: surf, mesh и plot3
> MATLAB предлагает несколько функций для отрисовки полученной матрицы `Z`.
> 
> 1. **Закрашенная поверхность (`surf`):**
> Создает сплошную поверхность, где цвет грани зависит от высоты (значения Z).
> ```matlab
> figure;
> surf(X, Y, Z);
> title('Сплошная поверхность (surf)');
> ```
> 
> 2. **Сетчатая (проволочная) поверхность (`mesh`):**
> Рисует только линии сетки. Некоторые варианты (например, Вар 9) строго требуют: *"Поверхность сделать сетчатой"*.
> ```matlab
> figure;
> mesh(X, Y, Z);
> title('Сетчатая поверхность (mesh)');
> ```
> 
> 3. **Трехмерные кривые (`plot3`):**
> Используется, когда нужно нарисовать линию в пространстве (а не поверхность), например, виток пружины или траекторию. Здесь `meshgrid` НЕ НУЖЕН, передаются одномерные векторы $t$, $x$, $y$, $z$.
> ```matlab
> t = 0:0.1:10*pi;
> x_curve = sin(t);
> y_curve = cos(t);
> z_curve = t;
> plot3(x_curve, y_curve, z_curve, 'r-', 'LineWidth', 2);
> ```

> [!abstract]+ Сложные фигуры: Гиперболоиды, цилиндры, эллипсоиды (Неявное задание)
> В заданиях часто даны уравнения фигур второго порядка в неявном виде. 
> Например, однополостный гиперболоид: $\frac{x^2}{16} + \frac{y^2}{4} - z^2 = 9$.
> 
> **Подход 1: Выражение Z (Аналитический)**
> Вы вручную выражаете $z$ из уравнения. Проблема в том, что корень дает $\pm$, то есть поверхность состоит из двух «половинок».
> ```matlab
> [X, Y] = meshgrid(-10:0.5:10, -10:0.5:10);
> % Выражаем Z: z^2 = X^2/16 + Y^2/4 - 9 -> Z = sqrt(...)
> Z_upper = sqrt(X.^2/16 + Y.^2/4 - 9); 
> Z_lower = -sqrt(X.^2/16 + Y.^2/4 - 9);
> 
> % Чтобы избежать комплексных чисел там, где под корнем минус:
> Z_upper(~isreal(Z_upper)) = NaN; 
> Z_lower(~isreal(Z_lower)) = NaN;
> 
> surf(X, Y, Z_upper); hold on;
> surf(X, Y, Z_lower);
> ```
> 
> **Подход 2: Функция `fimplicit3` (Современный и рекомендуемый)**
> Позволяет строить неявные поверхности без ручного выражения переменной и возни с сетками. Идеально для эллиптических цилиндров и сфер.
> ```matlab
> figure;
> % Передаем анонимную функцию неявного уравнения f(x,y,z) = 0
> f = @(x, y, z) (x.^2)/16 + (y.^2)/4 - z.^2 - 9;
> 
> % Задаем границы [xmin xmax ymin ymax zmin zmax]
> bounds = [-20 20 -10 10 -15 15]; 
> fimplicit3(f, bounds, 'EdgeColor', 'none', 'FaceAlpha', 0.8);
> title('Однополостный гиперболоид');
> ```

> [!warning]+ Оформление 3D-графиков: Оси, цветовая шкала и освещение
> Требования к 3D графике строже, так как без форматирования визуализация может превратиться в нечитаемое пятно. В заданиях (например, Вар 1) может быть указано: *"с цветовой шкалой и двумерной интерполяцией цветов"*.
> 
> ```matlab
> surf(X, Y, Z);
> 
> % 1. Подписи трех осей (ОБЯЗАТЕЛЬНО)
> xlabel('Ось X');
> ylabel('Ось Y');
> zlabel('Ось Z');
> 
> % 2. Цветовая шкала (легенда высот)
> colorbar; 
> 
> % 3. Интерполяция цветов граней (убирает черную сетку, делает градиент плавным)
> shading interp; 
> 
> % 4. Смена цветовой палитры (по умолчанию используется parula)
> colormap jet; % Доступны: jet, hot, cool, hsv, gray, autumn
> 
> % 5. Настройка угла обзора (Азимут, Угол возвышения)
> view(45, 30); 
> ```

> [!example]+ Сечение поверхности плоскостью (Найти площадь сечения при z = 0)
> Многие варианты требуют найти площадь сечения фигуры. 
> Если эллиптический цилиндр $x^2 + 4y^2 = 16$ сечется плоскостью $z = 0$, в сечении образуется эллипс $x^2 + 4y^2 = 16$.
> 
> **Аналитическое вычисление (для вывода ответа в консоль):**
> Каноническое уравнение эллипса: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$.
> Делим наше уравнение на 16: $\frac{x^2}{16} + \frac{y^2}{4} = 1$. Следовательно, $a^2 = 16 \Rightarrow a = 4$, $b^2 = 4 \Rightarrow b = 2$.
> Площадь эллипса: $S = \pi \cdot a \cdot b$.
> ```matlab
> a = 4;
> b = 2;
> S_section = pi * a * b;
> disp(['Площадь сечения при z=0: ', num2str(S_section)]);
> ```

> [!example]+ Объявление символьных переменных (syms) и подстановка
> Чтобы MATLAB не требовал числовых значений переменных при вычислении формулы, их нужно объявить символьными с помощью команды `syms`.
> 
> **Базовый синтаксис:**
> ```matlab
> syms x y a b t; % Создание символьных переменных
> 
> % Теперь можно записать аналитическую функцию
> f = a * x^2 + b * x; 
> 
> % Обратите внимание: при работе с syms не нужны точки (.*, .^)!
> % Здесь f - это алгебраическое выражение, а не массив.
> ```
> 
> **Подстановка чисел (subs) и конвертация в double:**
> Если после символьных преобразований нужно получить число, используется `subs` (подстановка) и `double` (преобразование символьной дроби/константы в число с плавающей точкой).
> ```matlab
> % Подставляем x = 2, a = 1, b = 3
> val = subs(f, [x, a, b], [2, 1, 3]); % val будет равно 1*2^2 + 3*2 = 10
> 
> % Вывод символьного ответа (например, pi/2 или sqrt(2)) в виде дроби
> sym_pi = sym(pi);
> disp(double(sym_pi)); % Выведет 3.1416
> ```

> [!note]+ Пределы (limit) и Производные (diff)
> Применяется для **Задачи 2** (нахождение предела) и **Задачи 1** в некоторых вариантах (поиск асимптот и экстремумов).
> 
> **Вычисление пределов:**
> Функция `limit(expr, var, val)` ищет предел выражения `expr`, когда переменная `var` стремится к `val`.
> ```matlab
> syms x;
> f_lim = (2*x^2 - 3*x - 8) / (x + 7);
> 
> % Предел при x -> 1
> L1 = limit(f_lim, x, 1);
> disp(['Предел равен: ', char(L1)]);
> 
> % Предел при x -> бесконечности (inf)
> f_inf = 9 / (4*x^4 + 12*x - 111);
> L2 = limit(f_inf, x, inf);
> ```
> 
> **Дифференцирование:**
> Функция `diff(expr, var, n)` находит $n$-ую производную выражения по переменной.
> ```matlab
> f_diff = sin(3*x);
> df = diff(f_diff, x);      % Первая производная: 3*cos(3*x)
> d2f = diff(f_diff, x, 2);  % Вторая производная: -9*sin(3*x)
> 
> % Поиск экстремумов (приравниваем производную к нулю)
> % Функция solve решает символьные уравнения
> roots = solve(df == 0, x); 
> ```

> [!abstract]+ Интегралы, длины дуг и объемы (int vs integral)
> В заданиях 5, 7, 8 требуется найти площади плоских фигур, длины кривых или объемы тел вращения.
> 
> **Подход 1: Символьное интегрирование (Аналитическое, точное)**
> Функция `int(expr, var, a, b)` вычисляет определенный интеграл. Если пределы `a` и `b` не указаны, вычисляется неопределенный интеграл.
> 
> *Пример: Вычисление длины дуги $L = \int_a^b \sqrt{1 + (y')^2} dx$ (строго по методичке)*
> ```matlab
> syms x;
> y = (2/3)*x^(3/2);
> 
> % 1. Находим производную
> dy = diff(y, x);
> 
> % 2. Составляем подынтегральное выражение
> L_expr = sqrt(1 + dy^2);
> 
> % 3. Интегрируем от 0 до 3
> L_sym = int(L_expr, x, 0, 3);
> disp(['Длина дуги: ', num2str(double(L_sym))]);
> ```
> 
> *Пример: Вычисление объема тела вращения вокруг оси OX: $V_x = \pi \int_a^b y^2 dx$*
> ```matlab
> syms x;
> y_vol = 2*x - x^2; % Верхняя парабола
> % Если фигура ограничена осью y=0, интеграл берется от корней функции.
> % Найдем точки пересечения с y=0:
> limits = solve(y_vol == 0, x); % Вернет [0; 2]
> 
> V = pi * int(y_vol^2, x, 0, 2);
> disp(['Объем тела вращения: ', num2str(double(V))]);
> ```
> 
> **Подход 2: Численное интегрирование (`integral`)**
> Если функция слишком сложная и символьный интеграл не берется, используется численное интегрирование. Переменные не `syms`, а "анонимные функции" `@(x)`.
> ```matlab
> % Объявляем численную функцию (ОБЯЗАТЕЛЬНО точки для массивов)
> f_num = @(x) sqrt(1 + (diff_val).^2); 
> L_num = integral(@(x) sqrt(1 + x), 0, 3); % Упрощенный пример для y'
> ```

> [!tip]+ Решение задач по физике (Механика, Термодинамика)
> Задача 4 всегда посвящена общей физике. Требуется либо решить систему алгебраических уравнений (законы Ньютона, уравнения Менделеева-Клапейрона), либо вычислить формулу.
> 
> **Организация кода для физической задачи:**
> 1. Создайте блок "Дано" (константы).
> 2. Запишите расчетные формулы (можно через `syms`, чтобы выразить неизвестную величину, а можно сразу вычислить численно, если формулы очевидны).
> 3. Выведите ответ с указанием единиц измерения.
> 
> *Пример структуры (Механика - соударение):*
> ```matlab
> % Дано:
> m_rod = 0.5;   % Масса стержня, кг
> L = 1.0;       % Длина стержня, м
> m_disk = 0.2;  % Масса шайбы, кг
> v_disk = 10;   % Скорость шайбы, м/с
> r = 0.25;      % Расстояние от центра масс, м
> 
> % Решение (символьный вывод уравнения баланса моментов импульса)
> syms omega v_center_after;
> 
> % 1. Момент инерции стержня относительно центра
> I_rod = (1/12) * m_rod * L^2;
> 
> % 2. Законы сохранения импульса и момента импульса (абсолютно упругий удар)
> % Использование функции solve для системы уравнений
> % eq1: m_disk * v_disk = m_disk * v_disk_after + m_rod * v_center_after
> % eq2: m_disk * v_disk * r = m_disk * v_disk_after * r + I_rod * omega
> % eq3: (m_disk * v_disk^2)/2 = (m_disk * v_disk_after^2)/2 + (m_rod * v_center_after^2)/2 + (I_rod * omega^2)/2
> 
> % Если аналитика сложна, формулу выводят на бумаге (как показано на Слайде 7 методички), 
> % а в MATLAB вписывают уже итоговый результат:
> 
> % Итоговая выведенная формула скорости центра масс:
> v_res = (m_disk * v_disk) / (m_rod + m_disk); % (Примерная формула для демонстрации)
> 
> disp(['Скорость центра масс: ', num2str(v_res), ' м/с']);
> ```
> **Важно для отчета:** Преподаватели ожидают, что в коде MATLAB будут комментарии с пояснениями физических законов (например, `% Уравнение состояния идеального газа`). Комментарии пишутся через знак процента `%`.
