# 1. $x^2 + 5y^2 - 6x + 20y + 4 = 0; \quad C(3-\sqrt{5}; 0)$  

## 1) Канонический вид:  
$$
\begin{gathered}
(x^2 - 6x) + (5y^2 + 20y) + 4 = 0 \\
(x^2 - 6x + 9 - 9) + 5(y^2 + 4y + 4 - 4) + 4 = 0 \\
(x^2 - 6x + 9) + 5(y^2 + 4y + 4) - 9 - 4\cdot5 + 4 = 0 \\
(x - 3)^2 + 5(y + 2)^2 = 25 \\
\frac{(x - 3)^2}{25} + \frac{(y + 2)^2}{5} = 1
\end{gathered}
$$  
Это каноническое уравнение **эллипса** вида $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$.  

## 2) Преобразование параллельного переноса:
$$
\begin{cases} x' = x - 3 \\ y' = y + 2 \end{cases} \Rightarrow \frac{x'^2}{25} + \frac{y'^2}{5} = 1
$$  
## 3) Характеристики эллипса:  
*   **Полуоси:**  
    $a^2 = 25 \Rightarrow a = 5$  
    $b^2 = 5 \Rightarrow b = \sqrt{5}$  
*   **Эксцентриситет:**  
    $\varepsilon = \frac{c}{a} = \frac{\sqrt{a^2 - b^2}}{a} = \frac{\sqrt{25 - 5}}{5} = \frac{\sqrt{20}}{5} = \frac{2\sqrt{5}}{5} = 0,4\sqrt{5}$  
*   **Центр $O'$:**  
    $x' = 0 \Rightarrow x_0 - 3 = 0 \Rightarrow x_0 = 3$  
    $y' = 0 \Rightarrow y_0 + 2 = 0 \Rightarrow y_0 = -2$  
    **$O'(3; -2)$**  
*   **Вершины:**  
    $A_+ = (x_0 + a; y_0) = (3 + 5; -2) = (8; -2)$  
    $A_- = (x_0 - a; y_0) = (3 - 5; -2) = (-2; -2)$  
    $B_+ = (x_0; y_0 + b) = (3; -2 + \sqrt{5})$  
    $B_- = (x_0; y_0 - b) = (3; -2 - \sqrt{5})$  
*   **Фокусы:**  
    $F_+ (x_0 + c; y_0) = (3 + 2\sqrt{5}; -2)$  
    $F_- (x_0 - c; y_0) = (3 - 2\sqrt{5}; -2)$  
* **Расстояние от точки C до фокусов:**  
	$P(F_-,C)=a + \varepsilon(x_c - x_0) = 5 + 0,4\sqrt{5}(3 - \sqrt{5} - 3) = 5 + 0,4\sqrt{5}(-\sqrt{5}) = 5 - 2 = 3$  
	$P(F_+,C)= a - \varepsilon(x_c - x_0) = 5 - 0,4\sqrt{5}(3 - \sqrt{5} - 3) = 5 + 2 = 7$  
## 4) Проверка принадлежности точки $C$ эллипсу: 
$$
\begin{rcases}
P_-+P_+ = 3 + 7 = 10\\
2a = 2 \cdot 5 = 10
\end{rcases}
=>\text{точка $C(3-\sqrt{5}; 0)$ лежит на эллипсе.}
$$
