17. Сворачиваемые блоки (Спойлеры)

Позволяют скрывать содержимое Callout-блока. Работает добавлением знака + или - после типа блока.

Что нужноСинтаксисПримерОписание
Свернутый блок (Спойлер)> [!NOTE]- Заголовок> [!NOTE]- Скрытое решение
> Ответ: 42		Блок будет закрыт по умолчанию. Раскрывается кликом.
Развернутый блок (Спойлер)> [!NOTE]+ Заголовок> [!INFO]+ Важно
> Текст		Блок будет открыт по умолчанию, но его можно свернуть.
Без заголовка> [!NOTE] (без текста)> [!TIP]
> Просто совет		Заголовок будет заменен на название типа (например, “Tip”).
